# Recursos Multimedia (Assets) — Hoja de Vida

Este directorio contiene las imágenes, el audio, el video y el documento utilizados en el sitio.

| Archivo | Uso |
| :--- | :--- |

| `poster.png` | Imagen de portada (poster) del video en `multimedia.html`. |

## `assets/audio/`

| Archivo | Uso |
| :--- | :--- |

## `assets/documents/`
| Archivo | Uso |
| :--- | :--- |

## Formatos y compatibilidad

Los archivos de audio y video se ofrecen en dos formatos (MP3/OGG y MP4/WEBM respectivamente) para asegurar compatibilidad entre distintos navegadores.
