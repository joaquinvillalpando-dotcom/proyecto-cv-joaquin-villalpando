Proyectos Destacados

Proyectos desarrollados de forma individual en distintas asignaturas de la carrera, como práctica de programación y diseño de sistemas:

Juego del Ahorcado

Descripción: Juego de adivinanza de palabras (ahorcado) para consola, con control de intentos y validación de letras repetidas.

Tecnologías utilizadas: C++

Rol desempeñado: Desarrollador único.

Resultado obtenido: Juego funcional, probado junto a compañeros de clase.

Tic-Tac-Toe (Tres en Línea)

Descripción: Implementación del clásico juego de tres en línea para dos jugadores, ejecutado por consola.

Tecnologías utilizadas: Python

Rol desempeñado: Desarrollador único.

Resultado obtenido: Programa completo con detección automática de ganador y de empate.

Sistema de Gestión de Cine

Descripción: Sistema de escritorio para el registro de películas, productos y ventas de un cine.

Tecnologías utilizadas: Java, JavaFX y archivos para persistencia de datos.

Rol desempeñado: Desarrollador del sistema.

Resultado obtenido: Sistema funcional para registrar películas, productos y ventas de un cine.

Base de Datos para "Librería El Estudiante"

Descripción: Diseño de esquema relacional para un negocio ficticio de venta de material escolar y de oficina, cubriendo inventario, proveedores y ventas.

Tecnologías utilizadas: Modelo entidad-relación y SQL.

Rol desempeñado: Diseñador del esquema relacional (proyecto de la asignatura Base de Datos I).

Resultado obtenido: Base de datos normalizada, con consultas SQL para reportes de ventas e inventario.

Esta misma Hoja de Vida

Descripción: Este sitio web: una hoja de vida interactiva y multipágina, desarrollada para la asignatura Tecnologías Web I.

Tecnologías utilizadas: HTML5 semántico, CSS3 (Flexbox y Grid) y JavaScript nativo.

Rol desempeñado: Desarrollador único.

Resultado obtenido: Sitio publicado en GitHub Pages y validado según los estándares de la W3C.
